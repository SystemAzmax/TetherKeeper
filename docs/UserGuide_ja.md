# テザリングキーパー 使い方

[English](UserGuide.md) | 日本語

テザリングキーパーは、一定の間隔で小さな通信を発生させて、iPhone のインターネット共有（テザリング）、Wi-Fi ルーター、モバイル回線などの「しばらく通信が無いと切れる」切断を起きにくくするアプリです。
切断を完全に防げることは保証できません。

- [1. はじめて使うとき](#1-はじめて使うとき)
- [2. 画面と操作](#2-画面と操作)
- [3. 困ったとき](#3-困ったとき)
- [4. アンインストール](#4-アンインストール)

## 1. はじめて使うとき

### 起動する

スタート メニューから「テザリングキーパー」を起動します。
「モニター」画面が開き、状態は「停止中」になっています。
はじめは何も通信しません。「開始」を押すと、キープアライブ（定期的な通信）が始まります。

### タスクトレイのアイコンを見つける

ウィンドウの「×」を押すと、アプリは終了せず、タスクトレイに入って動き続けます。
アイコンは、タスクバーの右端（時計の近く）に表示されます。
見当たらないときは、タスクバーの「^」（隠れているインジケーター）を押すと、その中にあります。

いつも見えるようにするには、「^」の中のアイコンを、タスクバーの時計の近くへドラッグします。

- アイコンをクリックすると、ウィンドウが表示されます。
- アイコンを右クリックすると、メニューの上部に今の状態（動作中かどうか、最後の結果、次回実行までの秒数、自動停止の予定）が表示されます。
  その下で、「ウィンドウを表示」「キープアライブを開始」（動作中は「キープアライブを停止」）「今すぐ実行」「自動停止を予約」（1 時間後・2 時間後に停止、予約を解除）「終了」を選べます。
  「自動停止を予約」で選ぶと、予約済みの日時は置き換わります。
- アプリを終了するには、モニター画面の「終了」か、トレイのメニューの「終了」を選びます。

### 通信の失敗に気づく

通信が 3 回（既定値）続けて失敗すると、テザリングなどの接続が切れているとみなして、Windows の通知で知らせます。
失敗が続いている間は、タスクトレイのアイコンの右下に赤い丸が付きます。
その後、通信が成功すると「通信が復旧しました」と通知し、赤い丸が消えます。

- 通知をクリックすると、ウィンドウが表示されます。
- 通知する回数と、通知するかどうかは「設定」画面で変えられます。

### キープアライブを始める

1. 「モニター」画面で「開始」を押します。
2. 状態が「動作中」になり、30 秒ごと（既定値）に通信します。結果は画面下のログに表示されます。
3. 「失敗」が続く場合は、「設定」画面で通信方式を切り替えます（「[3. 困ったとき](#3-困ったとき)」を参照）。

パソコンを起動したら自動で動くようにするには、「設定」画面で「Windows ログイン時にアプリを起動する」と「アプリ起動時に自動で開始する」の両方をオンにして、「保存」を押します。

### テザリングにつないだときだけ動かす

テザリングにつないだら開始し、切れたら停止するようにできます。自宅の Wi-Fi などでは動かさずに済みます。

1. パソコンをテザリングにつなぎます。
2. 「設定」画面で「指定したネットワークに接続したら開始し、切断したら停止する」をオンにします。
3. 「接続中のネットワークから選ぶ」で、テザリングのネットワークを選びます。Wi-Fi は iPhone の名前（ネットワーク名）で表示されます。
4. 「保存」を押します。

- 接続が変わってから約 5 秒後に、開始・停止します。
- 切断して停止したときは、通知で知らせます（「失敗が続いたときと、復旧したときに通知する」がオンの場合）。
- テザリングにつないだまま自分で「停止」した場合は、つなぎ直すまで自動では開始しません。
- ほかのネットワークで自分で「開始」した場合は、自動では停止しません。
- アプリが動いていないと開始できません。「Windows ログイン時にアプリを起動する」もオンにしておくと便利です。

## 2. 画面と操作

画面の下の「モニター」「履歴」「設定」で、画面を切り替えます。

### モニター

| 項目 | 説明 |
| --- | --- |
| 状態 | 「停止中」「動作中」と、通信方式・送信先・間隔、次回実行までの秒数を表示します。失敗が続いているときは「動作中（〇 回連続失敗）」と表示します |
| 開始 / 停止 | キープアライブを開始・停止します |
| 今すぐ実行 | 間隔を待たずに、すぐに 1 回通信します |
| 終了 | アプリを終了します（「×」はタスクトレイに入るだけで、終了しません） |
| 自動停止 | 日付と時刻を選んで「予約」を押すと、その日時にキープアライブを停止します。「1 時間後」「2 時間後」を押すと、今からその時間後に予約します。停止すると予約は解除されます。「解除」で予約を取り消せます。アプリは終了しません（「設定」の「自動停止したらアプリも終了する」をオンにすると終了します）。毎週の自動停止を使っている場合は、その予定も表示します |
| 通信量 | キープアライブの動作中に数えた通信量の累計です。「設定」で上限を決めると、上限に達したときに停止します。「リセット」で 0 に戻します |
| 合計 / 成功 / 失敗 / 連続失敗 | 通信した回数です。予備の通信方式で成功した場合は「成功」に数え、その回数をその下に表示します。「統計リセット」で 0 に戻します |
| ログ | 通信の結果などの記録です。「ログ消去」は画面の表示だけを消します（ファイルのログは残ります）。「保存先」は、ログと設定の保存フォルダーを開きます |

通信量について:

- 数えるのは、インターネットへの通信に使われているネットワーク アダプター（有線 LAN と Wi-Fi の両方につながっている場合は、Windows が通信に選んだ方）の送受信量です。ほかのアプリの通信も含みます。
- 計測は 5 秒ごとのため、上限を少し超えてから止まることがあります。
- キープアライブを止めても、ほかのアプリの通信は止まりません。
- 上限に達している間は「開始」できません。「リセット」すると、また開始できます。

### 履歴

キープアライブの動作中に記録した通信の結果を、時間帯ごとに集計します。「何時ごろによく切れるか」を確かめるのに使います。

| 項目 | 説明 |
| --- | --- |
| 期間 | 「直近 24 時間」「直近 7 日」「直近 30 日」から選びます |
| 更新 | 最新の記録で集計し直します |
| CSV に書き出す | 選んだ期間の結果を、ダウンロード フォルダーに CSV ファイルで書き出し、エクスプローラーで表示します。Excel で開けます |
| 合計 | 期間の通信の回数と、成功・失敗の回数、失敗の割合です |
| 時間帯ごとの失敗 | 0〜23 時の時間帯ごとに、通信した回数と失敗した回数、失敗の割合を表示します。赤い棒は失敗の割合で、最も高い時間帯がいちばん長くなります |

- 予備の通信方式で成功した回は、成功に数えます。
- 記録は 30 日分を残します。ログと同じフォルダー（モニター画面の「保存先」で開けます）の `history` に、日ごとの CSV ファイルとして保存しています。

### 設定

変更したら「保存」を押します。「既定値に戻す」は、入力欄を既定値に戻します（「保存」を押すまで反映されません）。

| 項目 | 説明 |
| --- | --- |
| 通信方式 | 「Ping (ICMP)」「HTTP HEAD」「TCP Connect」から選びます。既定値は「Ping (ICMP)」です |
| 予備の通信方式 | 通信方式で失敗したときだけ、この方式で 1 回やり直します。どちらも失敗したときだけ「失敗」になります。送信先は、その方式の欄の値を使います。既定値は「使わない」です（「[「失敗」が続く](#失敗が続く)」を参照） |
| Ping 送信先（ホスト名 / IP アドレス） | Ping を送る先です。既定値は `1.1.1.1` です |
| HTTP HEAD 送信先 URL | HTTP HEAD を送る先です。既定値は `http://www.msftconnecttest.com/connecttest.txt` です |
| TCP 接続先ホスト / ポート | TCP Connect で接続する先です。既定値は `1.1.1.1` と `443` です |
| 実行間隔（秒） | 通信する間隔です。5〜3600 秒で、既定値は 30 秒です。切断される場合は 15〜30 秒程度にします。下に、選んだ通信方式と間隔での通信量の目安（1 時間あたりと 24 時間あたり）が表示されます |
| タイムアウト（ミリ秒） | 応答を待つ時間です。500〜30000 ミリ秒で、実行間隔より短くします。既定値は 3000 ミリ秒です |
| 通信量の上限（MB） | 通信量の累計がこの値に達したら停止します。0 は上限なしです（既定値） |
| 毎週決まった時刻に停止する | オンにすると、選んだ曜日の決まった時刻に、キープアライブを停止します（動作中のときだけ）。日時の予約と違い、停止しても解除されません。既定値はオフです |
| 自動停止したらアプリも終了する | オンにすると、日時の予約か毎週の自動停止で停止したときに、アプリも終了します。通信量の上限やネットワークの切断で停止したときは終了しません。既定値はオフです |
| 通知する連続失敗の回数 | この回数だけ続けて失敗すると、通知して、タスクトレイのアイコンに赤い丸を付けます。1〜100 回で、既定値は 3 回です |
| 失敗が続いたときと、復旧したときに通知する | オフにすると通知を出しません（アイコンの赤い丸は付きます）。既定値はオンです |
| キープアライブの動作中はスリープしない | オンにすると、キープアライブの動作中は、操作しないで放置してもパソコンが自動でスリープしなくなります。既定値はオフです（「[パソコンのスリープから復帰したあと](#パソコンのスリープから復帰したあと)」を参照） |
| 指定したネットワークに接続したら開始し、切断したら停止する | オンにすると、「ネットワーク名」のネットワークに接続したときに開始し、切断したときに停止します。既定値はオフです（「[テザリングにつないだときだけ動かす](#テザリングにつないだときだけ動かす)」を参照） |
| ネットワーク名 | 自動で開始・停止するネットワークの名前です。「接続中のネットワークから選ぶ」で選べます。「更新」で一覧を取り直します |
| アプリ起動時に自動で開始する | オンにすると、アプリを起動したときにキープアライブを開始します |
| Windows ログイン時にアプリを起動する | オンにすると、Windows にサインインしたときに、タスクトレイに入った状態でアプリが起動します |

通信量の目安について:

- キープアライブ自身の通信だけの目安です。回線や、IPv4・IPv6 の違いで変わります。
- ほかのアプリの通信、名前解決（送信先にホスト名を入れた場合）、予備の通信方式でやり直した分は含みません。
- 「通信量の上限（MB）」で数える量は、ほかのアプリの通信も含むため、目安より多くなります。

通信方式の違い:

| 通信方式 | 向いている場面 |
| --- | --- |
| Ping (ICMP) | 通信量が最小です（30 秒間隔で 1 時間 約 14〜19 KB、24 時間で 約 0.35〜0.46 MB）。ICMP を遮断するネットワークでは失敗します |
| HTTP HEAD | プロキシ環境や、ICMP が遮断された環境でも通りやすい方式です。通信量は Ping より多くなります |
| TCP Connect | 接続して、すぐに切断します。ポート 443 などへの接続が許可されている必要があります |

### アプリの情報

「設定」画面の最後にあります。

| 項目 | 説明 |
| --- | --- |
| このアプリについて | アプリのバージョンなどを表示します |
| ライセンス情報 | アプリが使用しているソフトウェアのライセンスを表示します |
| 使い方 | このページ（使い方ガイド）を Web ブラウザーで開きます |

## 3. 困ったとき

### 起動したのに、ウィンドウが表示されない

アプリはタスクトレイに入っている可能性があります。「[タスクトレイのアイコンを見つける](#タスクトレイのアイコンを見つける)」を見て、アイコンをクリックしてください。
Windows ログイン時に起動した場合は、ウィンドウを出さずにタスクトレイに入った状態で起動します。

### 「失敗」が続く

- 「Ping (ICMP)」で失敗する場合は、ネットワークが ICMP を遮断している可能性があります。「設定」で「HTTP HEAD」に切り替えてみてください。
- 会社などでプロキシを使うネットワークでは、「HTTP HEAD」を使います。
- 送信先を変えた場合は、入力が正しいか確かめてください。「既定値に戻す」で元の送信先に戻せます。
- 送信先の不調や、ネットワークによる遮断で 1 つの方式だけが失敗することがあります。「予備の通信方式」を選ぶと、失敗したときに別の方式でやり直し、回線がつながっていれば「成功」になります（ログには「予備で成功」と残ります）。予備でも成功が続く場合は、通信方式を予備の方式に切り替えると、やり直しの分の通信が減ります。

### 失敗が続いているのに、通知が出ない

- 「設定」画面で「失敗が続いたときと、復旧したときに通知する」がオンになっているか確かめてください。
- Windows の「設定」→「システム」→「通知」で、通知と、テザリングキーパーの通知がオンになっているか確かめてください。
- 「応答不可」（集中モード）がオンの間は、通知が表示されず、通知センターにだけ残ります。

### それでも切断される

「設定」で「実行間隔（秒）」を 15〜30 秒程度に短くしてみてください。
回線や機器によっては、通信していても切断されることがあります。

### 「開始」できない

「上限に達したため、開始できません。」と表示されている場合は、通信量の累計が「通信量の上限（MB）」に達しています。
モニター画面の通信量の「リセット」を押すか、「設定」で上限を変えてください。

### テザリングにつないでも、自動で開始しない

- 「設定」の「ネットワーク名」が、テザリングのネットワークの名前と同じか確かめてください（大文字と小文字も区別します）。テザリングにつないだ状態で「更新」を押し、一覧から選び直すと確実です。
- USB や Bluetooth でつなぐと、Wi-Fi とは別の名前になります。つなぎ方を変えた場合は、選び直してください。
- 通信量の上限に達している間は、開始しません（「[「開始」できない](#開始できない)」を参照）。
- テザリングにつないだまま自分で「停止」した場合は、つなぎ直すまで自動では開始しません。

### 「Windows ログイン時にアプリを起動する」をオンにできない

タスク マネージャーの「スタートアップ アプリ」で、テザリングキーパーが無効にされていると、アプリからはオンにできません（Windows の仕様です）。
タスク マネージャーを開き、「スタートアップ アプリ」でテザリングキーパーを「有効」にしてください。

### パソコンのスリープから復帰したあと

スリープから復帰すると、5 秒後に通信を再開します。スリープ中は通信しません。

スリープ中にテザリングが切れて困る場合は、「設定」で「キープアライブの動作中はスリープしない」をオンにします。
キープアライブの動作中は、操作しないで放置しても自動でスリープしなくなります。止めるのはスリープだけで、画面はいつもどおり消えます。

- ふたを閉じる、電源ボタンを押す、スタート メニューで「スリープ」を選ぶ、などの操作をしたときは、スリープします（Windows の仕様です）。
- ノート PC では、バッテリーの消費が増えます。
- モダン スタンバイに対応したノート PC をバッテリーで使っている場合は、Windows の「スリープまでの時間」を過ぎてから 5 分たつとスリープします（Windows の仕様です）。
- キープアライブを停止すると、スリープの設定は元に戻ります。

## 4. アンインストール

スタート メニューで「テザリングキーパー」を右クリックし、「アンインストール」を選びます。

- 設定、通信量の累計、ログ、通信の結果の履歴は、アンインストールすると削除されます（ダウンロード フォルダーに書き出した CSV ファイルは残ります）。
- 「Windows ログイン時にアプリを起動する」の設定も削除されます。
